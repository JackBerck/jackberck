## 🎯 How I Learn

I like learning by **building**.

Instead of:

```text
"I'll learn this technology first."
```

I usually prefer:

```text
"I have an idea."
       ↓
"Can I build it with this?"
       ↓
"Why doesn't it work?"
       ↓
"Google."
       ↓
"Still doesn't work."
       ↓
"Read the documentation."
       ↓
"Oh..."
       ↓
"It works."
       ↓
"Now I understand it."
```

This has been surprisingly effective.
